# Volatility-gated LSTM–Attention

PJM(COMED) 하루 전 전력가격 예측에서 **예측 시점에 알 수 있는 전날 가격 변동성으로 기본 LSTM(A)과 사례 어텐션 모델(C)의 결합 비율을 학습하는** 실험이다. 팀의 관찰("고변동일에는 C, 평상시에는 A")을 먼저 데이터로 점검했고, 테스트 정답을 쓰지 않는 rolling-origin OOF 예측을 만든 뒤 작은 MLP 게이트를 학습했다. 게이트는 A와 고정 가중 결합보다 좋지만, 단순 평균을 넘는다는 증거는 얻지 못했다.

## 이름 대응

| 이 문서   | 기존 README·결과 폴더 | 내용                                      |
| ------ | --------------- | --------------------------------------- |
| A      | A (LSTM)        | 과거 168시간 가격·수요 예보 + 목표일 수요 예보 → 24시간 가격 |
| C      | C (CaseAttn)    | LSTM + 검색한 과거 유사일의 특징·실제 가격에 대한 어텐션     |
| E50    | —               | A와 C의 단순 평균                             |
| Efixed | —               | 게이트 학습 구간에서 최소제곱으로 정한 고정 가중치 결합         |
| alpha  | —               | C의 비중                                   |

A·C는 기존 스크립트(`train_01_baseline.py`, `train_02_bc.py`)를 수정하지 않고 import해서 같은 순서로 학습했다. 1 에폭 손실은 저장된 로그와 소수 9자리까지 같지만, 이후 부동소수점 차이가 누적되어 최종 수치는 저장 결과와 다르다(seed 42: A MAE 4.318 vs 저장값 4.378, C 4.122 vs 4.074). 그래서 2018 평가는 이 기기에서 재학습한 A·C(`retrained`)와 저장된 A·C(`saved_abc`) 두 가지로 보고한다.

## 평가 분할

각 origin은 배포 절차 `train | val 364일(early stopping, k 선택) | block 364일(예측만)`을 과거 시점에서 그대로 반복한다. block의 실제 가격은 그 origin의 A·C 학습, early stopping, k 선택, 표준화 어디에도 쓰이지 않는다.

| origin | 학습 | 검증 | block (OOF 예측) | 용도 |
| --- | --- | --- | --- | --- |
| `o2015` | 2013 | 2014 | 2014-12-30 ~ 2015-12-28 | 게이트 학습 |
| `o2016` | 2013–2014 | 2015 | 2015-12-29 ~ 2016-12-26 | 게이트 학습 |
| `o2017` | 2013–2015 | 2016 | 2016-12-27 ~ 2017-12-25 | 게이트 검증 / 보조 평가 |
| `o2018` | 2013–2016 | 2017 | 2017-12-26 ~ 2018-12-24 | 최종 평가 (기존 테스트와 같은 구간) |

- `o2018` 평가: 게이트 학습 = `o2015`+`o2016`, 게이트 검증 = `o2017`.
- `o2017` 평가(보조): 게이트 학습 = `o2015`, 게이트 검증 = `o2016`.

seed 42–44. 아래 수치는 seed 3개 평균. 유의성은 seed 평균 예측의 일 손실(MSE) 차이에 대한 주 단위 블록 부트스트랩 95% 신뢰구간이다.

## 실험 경과와 결과

### 1단계: 저장소 감사

- `PJM_error_analysis/results/abc/.../predictions.csv`는 테스트 구간 364일만 담는다. train·val 예측은 없다.
- `.pt` 체크포인트는 저장소에 없다. 게이트를 학습할 A·C 예측이 없어서 재학습이 필요했다.
- C는 학습된 A가 아니라 **A의 초기 가중치**에서 출발해 LSTM까지 함께 학습한다. 학습된 A는 유사일 검색에만 쓰인다.
- A·C 모두 검증 연도로 early stopping을 하고 C의 k도 검증 연도로 고른다. 따라서 본 모델의 검증 예측은 게이트 학습에 쓰지 않았다.

### 진단: 팀의 관찰은 데이터로 확인되는가

저장된 2018 테스트 예측만 읽어 점검했다(아무것도 학습하지 않음, `analyze_volatility_gate.py diagnostic`). 구간 기준값은 학습 기간에서 계산했다.

| 구간 (전날 변동성) | 일수 | A RMSE | C RMSE | C가 이긴 날 비율 | C 이득 중 비중 |
| --- | --- | --- | --- | --- | --- |
| 하위 50% | 152 | 4.68 | 4.78 | 0.39 | −0.03 |
| 중간 (50–90%) | 179 | 6.53 | 5.72 | 0.52 | 0.36 |
| 상위 10% | 33 | 16.72 | 12.95 | 0.63 | 0.67 |
| 2018년 1월 | 31 | 18.89 | 13.72 | 0.67 | 0.96 |
| 2018년 1월 제외 | 333 | 5.23 | 5.21 | 0.46 | 0.04 |

1. **방향은 맞지만 관계는 약하다.** 전날 변동성과 C의 일별 이득 사이 순위상관은 0.18~0.23이다.
2. **C의 이득은 2018년 1월에 몰려 있다.** MSE 이득의 96%가 1월에서 나오고, 1월을 빼면 A와 C의 RMSE가 같다.
3. **변동성만으로는 놓치는 날이 있다.** 이득이 두 번째로 큰 2018-01-02는 전날 표준편차가 12.6으로 학습 기간 90% 분위수(13.4)보다 낮다.
4. **A와 C의 오차 상관은 0.83~0.89다.** 결합으로 얻을 여지가 원래 작다.

### 게이트형 결합 방법

> ŷ = (1 − alpha) · ŷ_A + alpha · ŷ_C,  alpha_d = sigmoid(MLP(x_d))

- **구조:** `in → 8 → 1`, ReLU, sigmoid. 하루에 alpha 하나를 24시간 전체에 적용한다. A·C는 고정이고 게이트만 학습한다.
- **입력:** 목표일 시작 전(D−1 23시까지)의 가격만 쓴다. 산포·추세·진동을 서로 다른 특징으로 둔다.

| 개념 | 특징 |
| --- | --- |
| 산포 | D−1 표준편차(`vol_std`), D−1 최대−최소, 최근 7일 표준편차 |
| 수준 | D−1 평균, 최근 7일 평균 |
| 추세 | D−1 평균 − D−2 평균, D−1 마지막 시간 − 첫 시간 |
| 진동 | D−1 인접 시간 변화량 절댓값 평균 |
| 추가한 특징 | 진동 지표 `osc_chop`(변화량 합 ÷ 범위), 변동성 충격 `vol_rel`, 수요 예보 변화 `load_chg` |

- **학습:** 손실은 결합 예측의 24시간 평균 MSE. Adam(lr 1e-3), batch 32, 최대 100 에폭, patience 10으로 기존 A·C와 같은 값이다. 입력 표준화는 게이트 학습 날만으로 계산한다. early stopping으로 에폭 수를 정한 뒤 학습+검증 구간으로 다시 학습한 모델을 평가한다.

### 학습형 게이트 3종

| 이름 | 입력 | 특징 |
| --- | --- | --- |
| `gate_vol` | 전날 표준편차 1개 | 최소 모델 |
| `gate_struct` | 요청 특징 8개 | 산포·수준·추세·진동 전체 |
| `gate_anchor` | 요청 특징 8개 | 마지막 층을 0으로 초기화해 Efixed에서 출발 |

| 모델             | 2018 MAE | 2018 RMSE | 2018 (저장 A·C) MAE | 2018 (저장 A·C) RMSE | 2017 MAE | 2017 RMSE |
| -------------- | -------- | --------- | ----------------- | ------------------ | -------- | --------- |
| A              | 4.22     | 7.45      | 4.28              | 7.46               | 3.09     | 4.74      |
| C              | 4.15     | 6.98      | 4.08              | **6.39**           | 3.11     | 4.79      |
| E50            | **4.03** | 7.01      | 4.01              | 6.68               | **2.93** | **4.59**  |
| Efixed         | 4.09     | 7.18      | 4.10              | 6.93               | 2.99     | 4.66      |
| **`gate_vol`** | 4.04     | **6.95**  | **3.97**          | 6.53               | 2.95     | 4.61      |
| `gate_struct`  | 4.04     | 7.06      | 4.03              | 6.75               | 2.99     | 4.67      |
| `gate_anchor`  | 4.09     | 7.18      | 4.10              | 6.93               | 2.99     | 4.65      |

| `gate_vol` 비교 | 2018      | 2018 (저장 A·C) | 2017      |
| ------------- | --------- | ------------- | --------- |
| vs A          | 유의하게 좋음   | 유의하게 좋음       | 유의하게 좋음   |
| vs C          | 유의한 차이 없음 | 유의한 차이 없음     | 유의하게 좋음   |
| vs E50        | 유의한 차이 없음 | 유의하게 좋음       | 유의한 차이 없음 |
| vs Efixed     | 유의하게 좋음   | 유의하게 좋음       | 유의하게 좋음   |

- **`gate_vol`은 A와 Efixed보다 일관되게 좋다.** 그러나 E50을 유의하게 넘은 것은 이미 분석된 저장 A·C 평가 하나뿐이다.
- **alpha는 가설 방향으로 움직인다.** 2018에서 전날 변동성 하위 50%는 평균 0.43, 중간 0.54, 상위 10%는 0.64다. 범위는 0.23~0.82로 0·1 포화는 없다.
- **`gate_anchor`는 실패했다.** Efixed의 가중치가 seed마다 0.51 / 0.03 / 0.39로 불안정한데, 게이트가 거기서 벗어나지 못했다(best epoch 0).
- **`gate_struct`는 2017 평가에서 과적합된다.** 학습 일수가 364일뿐이라 alpha가 0.001~0.997로 퍼지고 16%가 0.05 미만이다.

### 한계

- `o2015`·`o2016`의 fold 모델은 1~2년치로만 학습되어 본 모델과 오차 성질이 다르다(`o2016` A MAE 약 6.0). Efixed가 불안정한 원인으로 보인다.
- OOF 구간(2015–2017)에는 2018년 1월 수준의 한파가 없다. 게이트는 그런 국면을 본 적이 없다.
- seed가 3개이고, seed 간 편차가 모델 간 차이보다 크다.
- 전날 고가격 이탈·지속 구간은 각각 11일뿐이다.

### 실행하지 않은 실험

- 다른 시장(NP·BE·DE 등)에 같은 설정을 그대로 적용하는 독립 재현.
- seed 5개 이상.
- `adaptive-weighted-LSTM-Attention/`의 규칙 게이트를 같은 A·C 예측에 적용한 직접 비교.

## 폴더 구조

이 실험의 파일은 모두 `volatility-gate/` 안에 있다. `PJM_error_analysis/`는 읽기만 한다(A·C 코드 `train_01_baseline.py`·`train_02_bc.py`, 데이터 `data/PJM.csv`, 저장된 결과 `results/abc/`).

```
volatility-gate/
├── README.md                    # 이 문서
├── requirements.txt
├── vgate_lib.py                 # 시간순 창 로더, 예측 시점 특징, Gating MLP, 지표
├── make_oof_predictions.py      # A·C rolling-origin OOF 예측 (기존 train_01/02 함수 재사용)
├── train_volatility_gate.py     # 게이트 학습, ablation, 예측·가중치·설정 저장
├── analyze_volatility_gate.py   # diagnostic(저장 예측 진단) / evaluate(게이트 평가, 그래프)
├── tests/test_volatility_gate.py  # 자동 테스트 20개
├── docs/                        # 요약 표(CSV)와 그래프(PNG)
└── results/                     # 실행하면 생긴다. 저장소에는 올리지 않는다
    ├── oof_ac/main/<origin>/seed_<s>/   # predictions.csv, metrics.json, 체크포인트
    ├── vgate_diagnostic/                # 진단 표·그래프
    └── vgate/main/                      # predictions_<gate>.csv, ablation.csv, gates/, analysis/
```

`results/`는 `adaptive-weighted-LSTM-Attention/`과 같은 기준으로 저장소에서 제외했다. 위 결과표의 근거가 되는 요약은 `docs/`에 있고, 나머지는 아래 실행 순서로 다시 만든다.

`predictions_<gate>.csv`의 열: `Date, actual, pred_A, pred_C, pred_E50, pred_Efixed, pred_gate, alpha, alpha_fixed, volatility_previous_day, seed, split, origin, source`.

## 실행 -> 확인용

```bash
cd volatility-gate
python -m pip install -r requirements.txt
python -m pytest tests/test_volatility_gate.py -q      # 20개 통과 확인
```

전체 실행 순서 (완료된 origin·seed는 건너뜀):

```bash
python analyze_volatility_gate.py diagnostic
python make_oof_predictions.py
python train_volatility_gate.py --out results/vgate/main
python analyze_volatility_gate.py evaluate --run results/vgate/main
```

- 위 수치는 맥 M1 CPU(threads 4)에서 얻었다. OOF 생성은 A·C 12회 학습으로 약 1시간 걸린다.
- 같은 seed라도 기기가 다르면 A·C 결과가 조금 달라지므로, 비교표에 들어가는 실행은 모두 한 기기에서 한다.
- 테스트는 게이트 학습이 테스트 블록과 그 이후 행에 영향받지 않는지를 직접 확인한다(테스트 블록 예측을 바꿔도 학습된 가중치가 비트 단위로 같다).
