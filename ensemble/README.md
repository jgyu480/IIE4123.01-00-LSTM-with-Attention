# 앙상블 실험 기록

전력가격 하루 전 예측(PJM, DE)에서 이미 있는 모델들을 결합해 단일 모델보다 나은 예측을 만드는 실험이다. 목표는 "특수한 상황에서도 크게 벗어나지 않는 것"이므로 RMSE(일별 MSE)를 주로 보고 MAE와 극단 구간 오차를 함께 본다.

## 1. 앙상블 방법론

| 방법 | 내용 | 상태 |
| --- | --- | --- |
| 배깅 | 학습 데이터를 무작위 복원추출해 같은 모델을 여러 개 학습 | **제외.** 시계열은 날짜 순서와 연속성이 중요해 무작위 추출이 맞지 않는다. 같은 모델의 seed 5개 평균(딥 앙상블)이 비슷한 역할을 이미 하고 있다 |
| 소프트 보팅 | 예측값의 평균. 균등 평균 또는 검증 연도로 정한 가중 평균 | **완료 (베이스라인)** |
| 부스팅 | 앞 모델의 잔차를 다음 모델이 학습 | 트리 부스팅 **완료 (베이스라인)**, LSTM 부스팅 **완료** |
| 메타 모델 스태킹 | 기반 모델들의 예측을 입력으로 받는 메타 모델이 최종 예측 | MLP **완료** (LSTM 부스팅보다 약함), 어텐션은 팀장님이 시도 (성능 좋지 않았음) |
| 동적 앙상블 | 날마다 비율 변경 | 특징 기반 게이트는 3번 시도해 모두 고정 비율을 못 이겼다. **최근 실제 오차로 비율을 갱신하는 온라인 결합(BOA)은 효과가 있었다** (4단계) |
| 딥 앙상블 확장 | 같은 신경망 여러 개 | **보류.** seed 5개 평균은 이미 쓰고 있다 |

## 2. 현재까지 있는 모델

| 모델 | 내용 | 비고 |
| --- | --- | --- |
| A | LSTM. 과거 168시간 가격·수요 예보 + 목표일 수요 예보 → 24시간 가격 | seed 5개 평균 |
| B | 학습된 A의 특징으로 찾은 과거 유사일 k개의 실제 가격 평균 | 학습 없음 |
| C | A + 과거 유사일에 대한 어텐션 (사례 어텐션) | seed 5개 평균. LEAR와 섞었을 때 A 대비 기여가 확인되지 않았다 |
| LEAR | 시간대별 Lasso 회귀, 매일 직전 데이터로 재학습 (Lago et al. 2021) | 학습 기간 56·84·1092·1456일 예측의 평균 |
| LEAR_S, LEAR_L | LEAR의 짧은 학습 기간(56·84일) 평균, 긴 학습 기간(1092·1456일) 평균 | LEAR = (LEAR_S + LEAR_L) / 2 |

LEAR + A, LEAR + C는 위 모델들의 가중 평균이므로 1절의 소프트 보팅에 속한다.

예측이 있는 곳:
- A·B·C·LEAR의 검증·테스트 연도 예측: `adaptive-weighted-LSTM-Attention/results/<tag>/<split>/export/` (`10_export_predictions.py`, PJM tag = `step1`, DE tag = `de`)
- LEAR의 전체 기간 예측(학습 기간 포함): `ensemble/results/<시장>/lear_all.npz` (`lear_history.py`)

## 3. 앙상블 실험 파이프라인

### 공통 평가 규칙

- **테스트 연도:** PJM 2018·2017, DE 2017·2016 (분할 `split2_2018`, `split1_2017`. DE는 데이터가 1년 앞서 끝나 테스트 연도가 한 해씩 이르다).
- **선택은 검증 연도로만 한다.** 비율, 트리 개수, 축소 계수, 손실 함수, 조합 선택 모두 검증 연도로 정한다. 테스트 결과를 보고 고르면 수치가 부풀려진다.
- **비교 기준:** LEAR 단독, 그리고 소프트 보팅 기준 모델 `valw(A + LEAR_S + LEAR_L)`.
- **유의성:** 일별 손실 차이의 주 단위 블록 부트스트랩 95% 신뢰구간 (5000회).
- **극단 구간:** 하루 평균 가격 − 직전 7일 평균이 학습 기간 상하위 2.5% 밖인 날을 사건으로 보고, 7일 이내의 사건을 묶은 구간 (`care.data.extreme_days`). 평가용으로만 쓴다.

### 1단계: 모델 간 오차 상관관계

테스트 연도 시간별 오차 상관 (네 연도 범위):

| 쌍 | 상관 | 해석 |
| --- | --- | --- |
| A – C | 0.92 ~ 0.97 | 사실상 같은 모델 |
| A – B | 0.65 ~ 0.83 | 다르게 틀리지만 B는 가장 약하다 |
| A – LEAR | 0.41 ~ 0.79 | 가장 다르게 틀리는 쌍 |
| A – LEAR_S | 0.37 ~ 0.72 | LSTM과 가장 덜 겹친다. 단독 성능은 약하다 |
| LEAR_S – LEAR_L | 0.72 ~ 0.91 | 같은 LEAR끼리도 꽤 다르다 |

결합할 가치가 있는 축은 **LSTM 계열(A 또는 C) ↔ LEAR 계열**이다.

### 2단계: 베이스라인

**소프트 보팅** (`soft_voting/combine_existing.py`). A·B·C·LEAR·LEAR_S·LEAR_L의 1~4개 조합 전부를 균등 평균과 검증 가중 평균으로 결합하고, 검증 RMSE가 가장 낮은 조합을 고른다. 네 연도 모두 "LSTM 하나 + LEAR_S + LEAR_L" 형태가 골라졌다(LSTM 0.35~0.45, LEAR_L 0.35~0.65, LEAR_S 0~0.2). B는 한 번도 골라지지 않았다. 아래 표의 소프트 보팅은 고정 조합 `valw(A + LEAR_S + LEAR_L)`이다.

**트리 부스팅** (`boosting/lear_tree_boost.py`).

> 최종 예측 = LEAR + c × 트리(특징)

- 1단계 LEAR, 2단계 scikit-learn `HistGradientBoostingRegressor`(XGBoost·LightGBM 계열)가 LEAR 잔차를 학습한다.
- LEAR는 매일 직전 데이터로만 재학습하므로 학습 기간 잔차도 사후 예측이다. fold 모델 없이 학습 데이터를 만들 수 있다.
- 입력 특징 20개: 달력(시간대·요일·월), LEAR(그 시간 예측, 하루 평균, LEAR_S − LEAR_L, LEAR − 전날 같은 시간 가격), 가격(전날·7일 전 같은 시간, 전날 평균·표준편차·최대·최소, 직전 7일 평균), 수요 예보 2개(그 시간 값, 하루 평균, 전날 대비 변화율).
- 학습 기간으로 학습하고, 검증 연도로 트리 개수(최대 500), 축소 계수 c(0~1), 손실 함수(제곱오차 / 절대오차)를 정한다.

**결과 (테스트 RMSE / MAE):**

| 테스트 연도 | LEAR | 소프트 보팅 | 트리 부스팅 |
| --- | --- | --- | --- |
| PJM 2018 | 6.372 / 3.737 | **5.574 / 3.411** | 5.892 / 3.564 |
| PJM 2017 | 4.225 / 2.531 | 4.040 / 2.443 | **4.013 / 2.431** |
| DE 2017 | 8.363 / 4.638 | 7.585 / **4.328** | **7.457** / 4.366 |
| DE 2016 | 5.548 / 3.174 | 5.321 / 3.431 | **5.237 / 3.166** |

**유의성 (일별 MSE / 일별 MAE, ○ 유의하게 좋음, × 유의하게 나쁨, − 차이 없음):**

| 비교 | PJM 2018 | PJM 2017 | DE 2017 | DE 2016 |
| --- | --- | --- | --- | --- |
| 소프트 보팅 vs LEAR | ○ / ○ | ○ / ○ | ○ / ○ | − / × |
| 트리 부스팅 vs LEAR | ○ / ○ | ○ / ○ | ○ / ○ | ○ / − |
| 트리 부스팅 vs 소프트 보팅 | × / × | − / − | − / − | − / ○ |

- **트리 부스팅은 네 연도 모두 LEAR보다 나빠지지 않았다.** MSE로는 네 연도 모두 유의하게 좋다.
- **소프트 보팅은 극단 구간이 큰 해에 강하다.** PJM 2018 극단 구간 MAE는 소프트 보팅 9.84, 트리 부스팅 11.05, LEAR 12.08이다.
- **소프트 보팅은 고정된 LSTM이 무너지는 해에 약하다.** DE 2016 테스트 MAE가 A 4.70으로 무너져 소프트 보팅 MAE가 LEAR보다 유의하게 나빴다. 트리 부스팅은 LSTM을 쓰지 않아 이 손해가 없다.
- 손실 함수는 PJM 두 해와 DE 2016에서 절대오차, DE 2017에서 제곱오차가 골라졌다. 제곱오차는 PJM 2014년 1월 한파 잔차에 끌려가 PJM 2018에서 LEAR보다 나빴다(RMSE 7.85).

### 3단계: 딥러닝 앙상블

(딥러닝 수업이니까)2단계의 ML 방식을 기준선으로 두고, 딥러닝이 맡는 결합 방식이 이를 넘는지를 본다. 목표는 트리 부스팅의 안정성(어디서도 LEAR보다 나빠지지 않음)과 소프트 보팅의 극단 구간 강점을 함께 얻는 것이다.

| 순서 | 방법 | 내용 | 상태 |
| --- | --- | --- | --- |
| 1 | **LSTM 부스팅** | LEAR 잔차를 A와 같은 구조의 LSTM이 학습. 최종 = LEAR + c × LSTM | **완료** |
| 2 | **MLP 스태킹** | 기반 모델 예측(A, LEAR_S, LEAR_L)과 상황 특징을 입력으로 MLP가 최종 24시간 예측 | **완료** |
| 3 | **어텐션 메타 모델** | 그날 상황을 보고 기반 모델들의 예측에 어텐션 가중치를 주는 구조(전문가 혼합) | 팀장님이 시도, 성능 좋지 않았음 |

**LSTM 부스팅** (`boosting/lear_lstm_boost.py`).

> 최종 예측 = LEAR + c × LSTM(입력)

- 1단계 LEAR, 2단계 LSTM이 LEAR 잔차(실제 − LEAR) 24시간을 한 번에 학습한다. 트리 부스팅과 같은 이유로 fold 모델 없이 학습 데이터를 만들 수 있다.
- LSTM 구조는 A와 같다(직전 168시간 가격·수요 예보 → LSTM(64), 목표일 수요 예보·요일과 함께 MLP). 여기에 목표일 LEAR 24시간 예측과 LEAR_S − LEAR_L 차이를 입력으로 더한다.
- 마지막 층을 0으로 초기화해 학습이 "LEAR 그대로"에서 시작한다.
- 학습 설정은 A와 같다(Adam 1e-3, batch 32, 최대 100 epoch, 검증 잔차 MSE로 조기 종료, patience 10). seed 5개 평균.
- 검증 연도로 축소 계수 c(0~1)와 손실 함수(MSE / L1)를 정한다. PJM 두 해는 L1, DE 두 해는 MSE가 골라졌다.

**결과 (테스트 RMSE / MAE):**

| 테스트 연도 | LEAR | 소프트 보팅 | 트리 부스팅 | LSTM 부스팅 |
| --- | --- | --- | --- | --- |
| PJM 2018 | 6.372 / 3.737 | **5.574** / 3.411 | 5.892 / 3.564 | 5.629 / **3.392** |
| PJM 2017 | 4.225 / 2.531 | 4.040 / 2.443 | 4.013 / 2.431 | **3.989 / 2.393** |
| DE 2017 | 8.363 / 4.638 | 7.585 / 4.328 | 7.457 / 4.366 | **7.196 / 4.153** |
| DE 2016 | 5.548 / 3.174 | 5.321 / 3.431 | 5.237 / 3.166 | **5.106 / 3.089** |

**극단 구간 MAE:**

| 테스트 연도 | LEAR | 소프트 보팅 | 트리 부스팅 | LSTM 부스팅 |
| --- | --- | --- | --- | --- |
| PJM 2018 | 12.08 | 9.84 | 11.05 | **9.40** |
| PJM 2017 | 20.02 | 20.21 | **18.70** | 19.37 |
| DE 2017 | 9.97 | 8.97 | 8.51 | **8.11** |
| DE 2016 | 11.55 | **9.62** | 10.25 | 10.01 |

**유의성 (일별 MSE / 일별 MAE):**

| 비교 | PJM 2018 | PJM 2017 | DE 2017 | DE 2016 |
| --- | --- | --- | --- | --- |
| LSTM 부스팅 vs LEAR | ○ / ○ | ○ / ○ | ○ / ○ | ○ / − |
| LSTM 부스팅 vs 소프트 보팅 | − / − | − / − | ○ / ○ | ○ / ○ |
| LSTM 부스팅 vs 트리 부스팅 | ○ / ○ | − / − | ○ / ○ | ○ / ○ |

- **LSTM 부스팅은 어느 연도에서도 비교 대상보다 유의하게 나빠지지 않았다.** LEAR보다는 네 연도 모두 MSE가 유의하게 좋다.
- MAE는 네 연도 모두, RMSE는 세 연도에서 가장 낮다. PJM 2018 RMSE만 소프트 보팅이 조금 낮지만 유의한 차이는 아니다.
- **LSTM이 무너지는 해에도 버틴다.** DE 2016에서 A 단독 MAE는 4.70이지만, LSTM 부스팅은 소프트 보팅보다 유의하게 좋았다. 매일 재학습하는 LEAR 위에 보정만 얹는 구조라 덜 흔들리는 것으로 보인다(해석이며 따로 검증하지 않았다).
- 극단 구간 MAE는 PJM 2018·DE 2017에서 가장 낮고, PJM 2017은 트리 부스팅, DE 2016은 소프트 보팅이 더 낮다. LEAR보다는 네 연도 모두 낮다.
- 한계: PJM 2017의 MSE 버전은 seed 대부분이 1 epoch에서 조기 종료됐다(주 모델은 L1이라 결과 표에는 영향 없음). 다중 비교 보정은 하지 않았다.

**MLP 스태킹** (`stacking/mlp_stack.py`).

> 최종 예측 = (A + LEAR_S + LEAR_L) / 3 + c × MLP(입력)

- 기반 모델은 소프트 보팅이 네 연도 모두 고른 A, LEAR_S, LEAR_L이다.
- **메타 모델 입력은 모두 사후 예측(OOF)이다.**
    - LEAR_S, LEAR_L: 매일 재학습하므로 모든 날이 사후 예측이다.
    - A: 학습 기간은 fold 모델 예측(`01_make_oof.py`, 각 fold는 자기 364일 블록 이전 날로만 학습), 검증·테스트 연도는 본 모델 예측이다. seed 5개 평균.
- MLP 입력: 기반 예측 3 × 24시간, 예측 시점에 아는 상황 특징 8개(`care.data.regime_features`: 전날 평균·표준편차, 직전 7일 대비 수준 변화, 저녁 변화, 전전날 대비 변화, 수요 예보 변화율 2개, 주말), 요일. 출력은 균등 평균에 대한 24시간 보정값이다.
- 구조: Linear(87 → 64) → ReLU → Dropout 0.1 → Linear(64 → 24). 마지막 층을 0으로 초기화해 균등 평균에서 시작한다.
- 학습 기간 OOF로 학습하고(PJM 2013-12-31~, DE 2013-01-07~), 검증 MSE로 조기 종료(patience 20), seed 5개 평균. 검증 연도로 c와 손실 함수(MSE / L1)를 정한다.

**결과 (테스트 RMSE / MAE):**

| 테스트 연도 | 균등 평균 (A + LEAR_S + LEAR_L) | 소프트 보팅 | LSTM 부스팅 | MLP 스태킹 |
| --- | --- | --- | --- | --- |
| PJM 2018 | 5.645 / 3.462 | **5.574** / 3.411 | 5.629 / **3.392** | 5.648 / 3.438 |
| PJM 2017 | 4.104 / 2.471 | 4.040 / 2.443 | **3.989 / 2.393** | 4.103 / 2.483 |
| DE 2017 | 7.742 / 4.345 | 7.585 / 4.328 | **7.196 / 4.153** | 7.570 / 4.401 |
| DE 2016 | 5.284 / 3.269 | 5.321 / 3.431 | **5.106 / 3.089** | 5.176 / 3.148 |

극단 구간 MAE (MLP 스태킹): PJM 2018 9.75, PJM 2017 20.59, DE 2017 8.65, DE 2016 10.01.

**유의성 (MLP 스태킹 기준, 일별 MSE / 일별 MAE):**

| --- | --- | --- | --- | --- |

| vs 트리 부스팅 | ○ / ○ | − / − | − / − | − / − |
| vs LSTM 부스팅 | − / − | × / × | × / × | − / − |

- **MLP는 출발점인 균등 평균에서 거의 움직이지 못했다.** 네 연도 중 세 연도에서 균등 평균과 유의한 차이가 없다. 유일하게 좋아진 DE 2016은 A가 무너진 해로, MLP가 A의 비중을 낮추는 쪽으로 보정한 것으로 보인다.
- **LSTM 부스팅을 넘지 못했다.** PJM 2017·DE 2017에서는 LSTM 부스팅보다 유의하게 나쁘다. 소프트 보팅과는 대체로 비슷하다.
- 원인 후보:
    - **학습 데이터가 적다.** 학습 일수가 728~1092일이고, 하루가 표본 하나다.
    - **학습 때와 평가 때의 A가 다르다.** 학습 기간 A는 fold 모델 예측이라 본 모델보다 약하다(PJM fold MAE 6.1~8.5, 본 모델 3.7). 그래서 MLP가 검증·테스트에서 만나는 A와 다른 A로 학습한다.
    - MSE 버전은 PJM 두 해에서 seed 대부분이 1 epoch에서 조기 종료됐다. 학습 기간에서 배운 보정이 검증 연도로 거의 옮겨지지 않는다는 뜻이다.
- 팀장님의 어텐션 메타 모델도 성능이 좋지 않았다. 같은 OOF 데이터 위의 두 메타 모델이 모두 약했으므로, 이 데이터에서는 메타 모델 방식보다 LEAR 위에 잔차를 얹는 부스팅 방식이 맞는 것으로 보인다.

### 4단계: BOA 온라인 결합 + LSTM 부스팅

팀장님의 BOA 파이프라인(브랜치 `results/all-lear-a-experiments-20261120_164542`의 `lear_a_simple_improvements/run.py`)에 LSTM 부스팅을 연결한 실험 2개다. 코드는 `boa/boa_lstm.py`.

**팀장님 파이프라인 (BOA5).** 모든 단계가 지나간 날의 실제 오차만 보고 매일 갱신하는 온라인 방식이다(검증·테스트 연도만 사용).

1. **TrainingRecent:** LEAR + β × (A − LEAR). 비율 β는 시간대별로, 지금까지 전체와 최근 14일의 실제 오차로 매일 다시 계산한다.
2. **보정 4종:** TrainingRecent에 최근 오차로 보정을 얹은 버전.
    - LevelShape: 하루 평균과 시간대별 모양 편향 보정
    - Reconcile: 하루·6시간 평균을 따로 예측(ridge, 매주 재학습)해 맞추기
    - BiasMix: 편향과 섞는 비율을 같이 보정
    - MeanError28_half: 최근 28일 평균 오차의 절반만큼 보정
3. **BOA (Bernstein Online Aggregation):** 위 5개 버전을 전문가로 두고, 전날까지의 오차로 비율을 매일 갱신한다.
4. **선택:** 검증 연도를 구간으로 나눈다. 0~59일은 준비, 60~181일은 보정 방법 선택, 182~272일은 BOA 설정(손실 함수, 시간대 묶음 수) 선택, 273~363일은 확인용이다. 테스트 연도는 선택에 쓰지 않는다.

**실험 2개:**

| 이름 | 연결 방식 | 무엇을 확인하나 |
| --- | --- | --- |
| **BOA6** | 팀장님 BOA 전문가 5개 + **LSTM 부스팅** (6번째 전문가) | LSTM 부스팅이 BOA에 없는 정보를 주는가 |
| **BOA5LB** | 파이프라인의 기반 모델을 LEAR에서 **LSTM 부스팅**으로 교체. TrainingRecent = LSTM 부스팅 + β × (A − LSTM 부스팅), 나머지는 그대로 | LSTM 부스팅 위에 온라인 보정을 얹으면 나아지는가 |

- 이식한 코드로 팀장님이 저장한 BOA5 테스트 예측을 그대로 재현했다(최대 차이 1.4e-13).
- **LSTM 부스팅은 검증 연도 앞 절반으로만 선택을 다시 했다**(`lear_lstm_boost.py --select-frac 0.5`, 결과 `lstm_val0.5/`). 조기 종료, c, 손실 함수를 검증 0~181일로만 정했으므로, BOA가 비율을 학습하는 182일 이후와 테스트 연도에서는 완전한 사후 예측이다.
- A는 레포의 현재 export를 쓴다. 팀장님 A(브랜치 보관본)는 PJM 2018에만 있어서 별도로 돌렸다(아래 참고).

**결과 (테스트 RMSE / MAE):**

| --- | --- | --- | --- | --- | --- |

| 테스트 연도 | BOA6의 LSTM 부스팅 비율 | β (A 비중), 기반 LEAR | β (A 비중), 기반 LSTM 부스팅 |

| PJM 2017 | 0.16 | 0.30 | 0.17 |
| DE 2017 | 0.27 | 0.51 | 0.25 |
| DE 2016 | 0.15 | 0.32 | 0.13 |

- **BOA6는 양쪽 부모보다 나빠진 적이 없다.**
    - 팀장님 BOA보다는 DE 두 해에서 유의하게 좋다.
    - LSTM 부스팅 단독보다는 MAE 기준으로 세 해에서 유의하게 좋다.
    - 어느 연도·지표에서도 둘 중 하나보다 유의하게 나쁘지 않아서, 목표("특수한 상황에서도 크게 벗어나지 않는 것")에 가장 맞는 후보다.
- **BOA5LB는 이득이 가장 크지만 한 번 졌다.**
    - PJM 2017과 DE 2017에서 가장 좋다. 극단 구간 MAE는 세 해에서 1등이다.
    - DE 2016 MAE는 BOA5보다 유의하게 나쁘다. A가 무너진 해(A 단독 MAE 4.70)인데, A를 LEAR와 직접 섞는 BOA5 쪽이 A의 비중을 매일 조절해 더 잘 버틴 것으로 보인다(해석이며 따로 검증하지 않았다).
- **팀장님 BOA와 LSTM 부스팅 단독은 서로 비슷하다.** 네 해 중 DE 2016 MAE 하나만 차이가 났다.
- **LSTM 부스팅은 A의 정보를 이미 상당 부분 쓰고 있다.** 기반을 LSTM 부스팅으로 바꾸면 A 비중 β가 0.30~0.51에서 0.13~0.25로 줄어든다.
- **최근 오차로 보정하는 온라인 단계는 항상 효과가 있다.** 팀장님 BOA는 자기 출발점보다 네 해 모두 유의하게 좋다. BOA가 가장 많이 믿은 전문가는 대부분 LevelShape(최근 하루 수준·시간대 모양 편향 보정)였다.
- **A 버전에 따라 결과가 꽤 달라진다.** 팀장님 A(테스트 MAE 4.003)로 돌린 PJM 2018 결과는 아래와 같다. 레포 A(4.028)로 돌리면 BOA5 RMSE가 5.508에서 5.602로 바뀐다. 최종 비교 전에 팀 안에서 A를 하나로 맞춰야 한다.

| PJM 2018, 팀장님 A | RMSE | MAE | 극단 구간 MAE |
| --- | --- | --- | --- |
| BOA5 | **5.508** | 3.334 | 9.51 |
| BOA6 | 5.579 | **3.306** | **9.24** |
| BOA5LB | 5.636 | 3.309 | 9.38 |

이 경우 세 방식 사이에 유의한 차이는 없다. BOA6과 BOA5LB는 LSTM 부스팅 단독보다 MAE가 유의하게 좋다.

- 한계:
    - 결합 방식을 여러 개 비교했지만 다중 비교 보정은 하지 않았다.
    - BOA5LB는 보정 방법을 고르는 구간(검증 60~181일)에서 LSTM 부스팅이 완전한 사후 예측이 아니다. 그래서 그 구간에서 LSTM 부스팅을 조금 더 믿었을 수 있다. 테스트 연도에는 영향이 없다.

주의할 점:
- **LSTM 쪽 비교 기준은 A로 둔다.** C는 대조 실험에서 기여가 없었으므로, C를 쓸 때는 같은 조건의 A 결과와 나란히 보고한다.

## 폴더 구조

```
ensemble/
├── README.md

├── soft_voting/
│   └── combine_existing.py     # 소프트 보팅: 오차 상관, 조합 전수 비교
├── boosting/
│   ├── lear_tree_boost.py      # 트리 부스팅: LEAR + HistGradientBoosting
│   └── lear_lstm_boost.py      # LSTM 부스팅: LEAR + 잔차 LSTM (GPU, 4개 연도 약 2분)
├── stacking/
│   └── mlp_stack.py            # MLP 스태킹: A·LEAR_S·LEAR_L OOF 예측 → MLP (GPU, 약 1분 30초)
├── boa/
│   └── boa_lstm.py             # 팀장님 BOA 파이프라인 + LSTM 부스팅 (BOA5·BOA6·BOA5LB, CPU 연도당 몇 분)
└── results/                    # 실행 결과 (git 제외)
```

## 실행

WSL의 conda 환경에서 실행한다. 앞 단계: `adaptive-weighted-LSTM-Attention/`의 01·05·06·08·10을 시장마다 실행해 두어야 한다(그 폴더 README 참고).

```bash
python ensemble/lear_history.py --market PJM            # DE는 --market DE
python ensemble/soft_voting/combine_existing.py
python ensemble/boosting/lear_tree_boost.py --markets PJM DE
python ensemble/boosting/lear_lstm_boost.py --markets PJM DE     # 트리 부스팅 결과가 있으면 함께 비교
python ensemble/stacking/mlp_stack.py --markets PJM DE           # 부스팅 결과가 있으면 함께 비교
python ensemble/boosting/lear_lstm_boost.py --markets PJM DE --select-frac 0.5   # BOA용 LSTM 부스팅
python ensemble/boa/boa_lstm.py                                   # 4개 연도, 레포 A
python ensemble/boa/boa_lstm.py --a-source lead --markets PJM --splits split2_2018   # 팀장님 A
```

팀장님 A로 돌리려면 브랜치의 export와 BOA 예측을 `boa/results/PJM/split2_2018/lead_export/`에 먼저 복사해 둔다(`predictions_val.csv`, `predictions_test.csv`, `lead_boa_predictions_test.csv`).

각 스크립트 결과:
- 트리 부스팅: `boosting/results/<시장>/<분할>/`
- LSTM 부스팅: 그 아래 `lstm/`, BOA용은 `lstm_val0.5/`
- MLP 스태킹: `stacking/results/<시장>/<분할>/`
- 위 셋은 모두 `predictions_{val,test}.csv`와 `summary.json`(선택된 설정, 테스트 지표, 부트스트랩)을 남긴다.
- BOA: `boa/results/<시장>/<분할>/a_<repo|lead>/`에 `scores.csv`, `bootstrap.csv`, `boa_weights.csv`, `selection.json`, `predictions_test.csv`를 남긴다. 연도별 요약은 `boa/results/summary_a_<repo|lead>.csv`다.
