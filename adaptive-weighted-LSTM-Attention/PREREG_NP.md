# NP 검증 사전 등록

NP(Nord Pool) 시장 실험을 돌리기 **전에** 가설, 판정 기준, 실행 설정을 고정한 문서다. NP의 모델 결과는 이 문서를 쓰는 시점까지 아무도 보지 않았다. NP 데이터에서 본 것은 시장별 극단 사건 수(아래 3절)뿐이다. 이 문서는 NP를 실행하기 전에 커밋해서 시점을 남긴다.

- PJM, DE: **탐색용**이다. 가설과 규칙은 여기서 나왔다. PJM 테스트 연도는 여러 번 봤기 때문에 확증 근거로 쓰지 않는다.
- NP: **확증용**이다. 아래 설정을 바꾸지 않고 한 번 실행하고, 결과는 좋든 나쁘든 그대로 보고한다.

## 1. 지금까지 확인한 사실 (PJM, DE)

용어: A = LSTM, B = 유사일 가격 평균, C = LSTM + 사례 어텐션, LEAR = 시간대별 Lasso(매일 재학습, 학습 기간 56/84/1092/1456일 평균). A·B·C는 seed 5개 평균 예측이다. 앙상블 비율은 검증 연도로만 정했다. 유의성은 일별 손실 차이의 주 단위 블록 부트스트랩 95% 신뢰구간이다. 테스트 연도는 PJM 2018·2017, DE 2017·2016이다.

| # | 사실 | 근거 |
| --- | --- | --- |
| F1 | A와 C는 거의 같이 틀린다 | 시간별 오차 상관 0.92~0.97 (네 테스트 연도) |
| F2 | 학습형 게이트(α를 로지스틱으로 학습)는 실패했다 | seed별 상수로 굳음, PJM 2018에서 규칙 게이트보다 유의하게 나쁨 |
| F3 | B는 다르게 틀리지만 약하다 | A·C와 상관 0.65~0.85, 테스트 MAE가 A·C 중 나은 쪽보다 15~41% 나쁨, 검증이 정한 앙상블 비중 0~0.2 |
| F4 | LEAR는 검증 연도 사전 기준(A·C와 상관 0.85 이하, MAE 5% 이내)을 네 번 모두 통과했다 | 상관 0.57~0.83, 검증 MAE가 A·C보다 6~24% 좋음 |
| F5 | **사례 어텐션은 기여하지 않았다** | LEAR+C vs LEAR+A: PJM 2018·DE 2017·DE 2016 유의한 차이 없음, PJM 2017은 LEAR+A가 유의하게 좋음 |
| F6 | LEAR+A 앙상블은 대체로 LEAR보다 좋지만 항상은 아니다 | 일별 MSE: PJM 2018·DE 2017 유의하게 좋음, PJM 2017·DE 2016 차이 없음. 일별 MAE: DE 2016에서 유의하게 나쁨 |
| F7 | 고정된 LSTM은 시장이 변하면 무너진다 | DE 2016 테스트 MAE: A 4.70, C 4.67 vs LEAR 3.17 (검증 연도에서는 3.82 vs 3.50) |
| F8 | 극단 구간에서 LEAR에 A를 섞으면 LEAR 단독보다 나아진다 (4개 중 3개) | 극단 구간 MAE: PJM 2018 9.58 vs 12.08, DE 2017 8.94 vs 9.97, DE 2016 9.70 vs 11.55. PJM 2017(극단일 1일)은 20.66 vs 20.02 |
| F9 | 변동성 전환 규칙(H3의 규칙)은 LEAR보다 나빠진 적이 없지만, 정적 앙상블보다는 대체로 나쁘다 | 일별 MSE vs LEAR: PJM 2018·DE 2017 유의하게 좋음, 나머지 차이 없음. vs LEAR+A: PJM 2018·PJM 2017·DE 2017 유의하게 나쁨, DE 2016은 MAE 유의하게 좋음 |

### 앞서 정리했던 주장의 정정

- "앙상블에서 급변 구간은 C가 보완한다"는 **철회**한다. LEAR+A가 같은 효과를 냈다(F5).
- "극단 구간에서는 LSTM이 세 해 모두 LEAR보다 낫다"는 **부정확**했다. A 단독은 4개 중 2개(DE 2017, DE 2016)에서만 나았고, PJM 2018은 C만 나았다. 맞는 표현은 F8이다.
- "LEAR+LSTM은 손해 없이 개선된다"는 **일반화되지 않는다**. DE 2016 MAE에서 손해였다(F6, F7).

## 2. NP에서 검증할 가설과 판정 기준

- **주 손실:** 일별 MSE. 목표가 "특수한 상황에서도 크게 벗어나지 않는 것"이라 RMSE 계열을 주로 본다.
- **보조 손실:** 일별 MAE.
- **유의:** 95% 신뢰구간이 0을 포함하지 않으면 유의하다고 본다. 다중 비교 보정은 하지 않으며, 네 가설을 함께 해석한다.
- **테스트 연도:** NP `split2_2018` = 2018년, `split1_2017` = 2017년. 두 해 모두 판정에 쓴다.

| 가설 | 비교 (`09_ensemble_analysis.py` 출력) | 예측 | 판정 |
| --- | --- | --- | --- |
| **H1** 사례 어텐션의 기여 | LEAR+C vs LEAR+A | 차이 없음 | 한 해 이상에서 LEAR+C가 일별 MSE로 유의하게 좋고, 다른 해에서 어느 손실로도 유의하게 나쁘지 않으면 "기여 있음". 아니면 **사례 어텐션 메커니즘을 최종 폐기**한다 |
| **H2** LEAR+LSTM 정적 앙상블 | LEAR+A vs LEAR | 일별 MSE에서 LEAR보다 나쁘지 않음 | 두 해 모두 일별 MSE로 유의하게 나쁘지 않고, 한 해 이상 유의하게 좋으면 "성립". 어느 해든 일별 MSE로 유의하게 나쁘면 "기각". MAE 결과도 함께 보고한다 |
| **H3** 변동성 전환 규칙 `Switch(LEAR,A)` | Switch vs LEAR, Switch vs LEAR+A | LEAR보다 나빠지지 않음. LEAR+A보다는 나쁠 수 있음 | 두 해 모두 LEAR보다 어느 손실로도 유의하게 나쁘지 않으면 "안전성 성립". 한 번이라도 유의하게 나쁘면 "기각" |
| **H4** 극단 구간 패턴 (기술 통계) | `ensemble_test.csv`의 `ext_MAE` | LEAR+A < LEAR | 두 해 모두 성립하면 "재현됨". A 단독과 C의 `ext_MAE`도 같이 보고한다 |

**H3 규칙 (고정):** 전날 시간별 가격의 표준편차가 학습 기간 날들의 90% 분위수를 넘으면 0.5·LEAR + 0.5·A, 아니면 LEAR만 쓴다. 신호와 기준값은 기존 규칙 게이트(`06_gate.py`)와 같다. PJM·DE 탐색에서 후보 4개를 비교했고, 이 규칙을 골랐다. 고른 기준은 "LEAR보다 한 번도 유의하게 나빠지지 않은 규칙 중 가장 단순한 것"이다. 정적 앙상블보다 좋다는 근거는 없다(F9). 이 가설은 성능 향상이 아니라 **안전성**을 검증한다.

## 3. NP 데이터에 대해 이미 본 것

시장별 극단 사건 수만 봤고, 모델 결과는 보지 않았다. 극단 사건 기준은 `data.extreme_days`와 같다(직전 7일 평균 대비 편차가 학습 기간 상하위 2.5% 밖, 7일 이내는 한 사건).

- 2018 테스트: 12개 사건
- 2017 테스트: 10개 사건
- 2018년 7–9월에는 가격 수준 자체가 오른 구간이 있다. 이 기준에서는 시작 부분만 극단으로 잡힌다.

## 4. 실행 설정 (고정)

```bash
CSV=data/epftoolbox/NP.csv
python scripts/01_make_oof.py --tag np --csv $CSV --device cuda
python scripts/05_train_case_attn.py --tag np --csv $CSV --device cuda --skip-folds
python scripts/06_gate.py --tag np --csv $CSV
python scripts/08_lear.py --tag np --csv $CSV
python scripts/09_ensemble_analysis.py --tag np --csv $CSV
```

- seed 42–46, 분할 2개, 에폭 100, patience 10, 배치 32, lr 1e-3 (스크립트 기본값)
- LEAR: 학습 기간 56/84/1092/1456일, 주 모델은 네 예측의 평균
- 앙상블 비율: 검증 연도 MSE 최소, 0.05 단위 격자
- 극단 구간: q = 0.975, 간격 7일
- 부트스트랩: 주 단위 블록, 5000회, seed 0
- 실행 장치: WSL Ubuntu, CUDA(RTX 3060), torch 2.13 + CUDA 13.0, scikit-learn 1.9.0
- 이 설정은 결과를 본 뒤 바꾸지 않는다. 오류 때문에 다시 실행해야 하면 원인과 변경 내용을 이 문서 아래에 기록한다.

## 5. NP 이후에 검증할 것 (이 문서의 판정 대상 아님)

1. **LEAR 구현 대조:** epftoolbox 공개 벤치마크 수치와 직접 구현 LEAR를 맞춰 본다.
2. **LSTM 주기적 재학습:** F7 때문이다. 월·분기 단위로 다시 학습한 A로 F6과 H2를 다시 본다.
3. **독립 시장 하나 더:** BE 또는 FR 중 하나. 둘은 외생변수와 극단 사건 시기가 겹쳐서 하나로 센다.
4. **공휴일 입력:** DE 급락 사건 일부가 공휴일이었다.
5. **확률예측:** LEAR와 LSTM을 분위수 회귀로 묶는 QRA로, "크게 벗어나지 않음"을 예측 구간 기준으로 평가한다.
6. **변동성 모델 연결:** H3의 전환 신호(전날 가격 표준편차)를 해영님의 변동성 모델로 바꾼 버전. 새 사전 등록이 필요하다.
