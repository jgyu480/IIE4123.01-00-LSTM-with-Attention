# Volatility-gated LSTM–Attention

PJM(COMED) 하루 전 전력가격 예측에서 **전날 가격 변동성으로 기본 LSTM(A)과 사례 어텐션 모델(C)의 결합 비율을 정하는** 실험이다. 테스트 정답을 쓰지 않는 rolling-origin OOF 예측으로 게이트를 학습하고 평가했다.

## 결론

1. **변동성 게이트는 단순 평균(E50)을 넘지 못한다.** 학습형 게이트, 고정 가중치, 고정 상승 곡선 모두 E50과 차이가 없거나 나빴다.
2. **처음 보고한 `gate_vol`의 좋은 수치는 학습의 결과가 아니었다.** 6회 중 4회가 학습되지 않은 무작위 초기 게이트였고, 초기값을 바꾸면 65%가 E50보다 나빴다.
3. **"고변동일에는 C"는 2018년 1월에 한정된 현상에 가깝다.** 2017년에는 패턴이 없고, seed를 늘리면 2018년 고변동일의 이득도 재현되지 않는다.
4. **유의하게 확인된 개선은 seed 평균뿐이다.** A·C를 각각 seed 10개로 평균한 뒤 반반 섞으면 4개 연도 모두에서 RMSE가 유의하게 낮아진다(2018년 6.98 → 6.71).
5. **B를 섞는 것은 유망하지만 근거가 약하다.** seed 평균 뒤에는 2018년에만 이득이 남고 유의하지 않다.

| 구성 | 2017 MAE | 2017 RMSE | 2018 MAE | 2018 RMSE |
| --- | --- | --- | --- | --- |
| A, seed 1개 | 3.157 | 4.838 | 4.224 | 7.358 |
| C, seed 1개 | 3.234 | 4.917 | 4.152 | 7.043 |
| E50, seed 1개 | 3.020 | 4.690 | 4.029 | 6.980 |
| **E50, seed 10개 평균** | **2.814** | **4.477** | 3.854 | 6.712 |
| ABC, seed 10개 평균 | 2.939 | 4.501 | **3.838** | **6.477** |

seed 1개 행은 seed 10개 각각의 RMSE를 평균한 값이다. 2017·2018년은 여러 번 분석한 구간이므로 이 수치는 독립적인 일반화 증거가 아니다.

## 평가 분할

각 origin은 배포 절차 `train | val 364일(early stopping, k 선택) | block 364일(예측만)`을 과거 시점에서 그대로 반복한다. block의 실제 가격은 그 origin의 A·C 학습, early stopping, k 선택, 표준화 어디에도 쓰이지 않는다.

| origin | 학습 | 검증 | block (OOF 예측) | 용도 |
| --- | --- | --- | --- | --- |
| `o2015` | 2013 | 2014 | 2014-12-30 ~ 2015-12-28 | 게이트 학습 |
| `o2016` | 2013–2014 | 2015 | 2015-12-29 ~ 2016-12-26 | 게이트 학습 |
| `o2017` | 2013–2015 | 2016 | 2016-12-27 ~ 2017-12-25 | 게이트 검증 / 보조 평가 |
| `o2018` | 2013–2016 | 2017 | 2017-12-26 ~ 2018-12-24 | 최종 평가 (기존 테스트와 같은 구간) |

- `o2018` 평가: 게이트 학습 = `o2015`+`o2016`, 게이트 검증 = `o2017`.
- `o2017` 평가(보조): 게이트 학습 = `o2015`, 게이트 검증 = `o2016`.

1~3절의 수치는 seed 42–44, 3개 평균이다. 4절부터는 seed 42–51, 10개를 쓴다. 유의성은 seed 평균 예측의 일 손실(MSE) 차이에 대한 주 단위 블록 부트스트랩 95% 신뢰구간이다.

## 1. 저장소 감사와 진단

### 저장소 감사

- `PJM_error_analysis/results/abc/.../predictions.csv`는 테스트 구간 364일만 담는다. train·val 예측은 없다.
- `.pt` 체크포인트는 저장소에 없다. 게이트를 학습할 A·C 예측이 없어서 재학습이 필요했다.
- C는 학습된 A가 아니라 **A의 초기 가중치**에서 출발해 LSTM까지 함께 학습한다. 학습된 A는 유사일 검색에만 쓰인다.
- A·C 모두 검증 연도로 early stopping을 하고 C의 k도 검증 연도로 고른다. 따라서 본 모델의 검증 예측은 게이트 학습에 쓰지 않았다.

### 진단: 팀의 관찰은 데이터로 확인되는가

저장된 2018 테스트 예측만 읽어 점검했다(아무것도 학습하지 않음, `analyze_volatility_gate.py diagnostic`). 구간 기준값은 학습 기간에서 계산했다.

| 구간 (전날 변동성) | 일수 | A RMSE | C RMSE | C가 이긴 날 비율 | C 이득 중 비중 |
| --- | --- | --- | --- | --- | --- |
| 하위 50% | 152 | 4.68 | 4.78 | 0.39 | −0.03 |
| 중간 (50–90%) | 179 | 6.53 | 5.72 | 0.52 | 0.36 |
| 상위 10% | 33 | 16.72 | 12.95 | 0.63 | 0.67 |
| 2018년 1월 | 31 | 18.89 | 13.72 | 0.67 | 0.96 |
| 2018년 1월 제외 | 333 | 5.23 | 5.21 | 0.46 | 0.04 |

1. **방향은 맞지만 관계는 약하다.** 전날 변동성과 C의 일별 이득 사이 순위상관은 0.18~0.23이다.
2. **C의 이득은 2018년 1월에 몰려 있다.** MSE 이득의 96%가 1월에서 나오고, 1월을 빼면 A와 C의 RMSE가 같다.
3. **변동성만으로는 놓치는 날이 있다.** 이득이 두 번째로 큰 2018-01-02는 전날 표준편차가 12.6으로 학습 기간 90% 분위수(13.4)보다 낮다.
4. **A와 C의 오차 상관은 0.83~0.89다.** 결합으로 얻을 여지가 원래 작다.

## 2. 게이트 설계

### 게이트형 결합 방법

> ŷ = (1 − alpha) · ŷ_A + alpha · ŷ_C,  alpha_d = sigmoid(MLP(x_d))

- **구조:** `in → 8 → 1`, ReLU, sigmoid. 하루에 alpha 하나를 24시간 전체에 적용한다. A·C는 고정이고 게이트만 학습한다.
- **입력:** 목표일 시작 전(D−1 23시까지)의 가격만 쓴다. 산포·추세·진동을 서로 다른 특징으로 둔다.

| 개념 | 특징 |
| --- | --- |
| 산포 | D−1 표준편차(`vol_std`), D−1 최대−최소, 최근 7일 표준편차 |
| 수준 | D−1 평균, 최근 7일 평균 |
| 추세 | D−1 평균 − D−2 평균, D−1 마지막 시간 − 첫 시간 |
| 진동 | D−1 인접 시간 변화량 절댓값 평균 |
| 추가한 특징 | 진동 지표 `osc_chop`(변화량 합 ÷ 범위), 변동성 충격 `vol_rel`, 수요 예보 변화 `load_chg` |

- **학습:** 손실은 결합 예측의 24시간 평균 MSE. Adam(lr 1e-3), batch 32, 최대 100 에폭, patience 10으로 기존 A·C와 같은 값이다. 입력 표준화는 게이트 학습 날만으로 계산한다. early stopping으로 에폭 수를 정한 뒤 학습+검증 구간으로 다시 학습한 모델을 평가한다.

## 4. 보완 실험: 게이트 절차 바로잡기

`exp_gate_fixes.py`. 최초 절차에는 허점이 있었다. early stopping이 한 번도 개선을 보지 못하면(best epoch 0) 무작위 초기 게이트가 그대로 최종 모델이 됐다. `gate_vol`은 6회 중 4회가 그랬다.

| 수정 | 내용 |
| --- | --- |
| `vol_fb` | best epoch 0이면 alpha를 0.5로 고정(E50으로 되돌림) |
| `vol_a50`, `struct_a50` | 마지막 층을 0으로 두고 alpha 0.5에서 출발 |
| `logit2` | alpha = sigmoid(a + b·z), 매개변수 2개, a = b = 0에서 출발 |

E50 대비 RMSE 차이 (seed 42–44 평균, 음수가 좋음):

| 게이트 | 2018 | 2018 (저장 A·C) | 2017 |
| --- | --- | --- | --- |
| `gate_vol` (최초) | −0.053 | −0.146 | +0.019 |
| `vol_fb` | +0.001 | −0.009 | +0.019 |
| `vol_a50` | +0.009 | +0.020 | +0.022 |
| `logit2` | +0.024 | +0.048 | +0.017 |
| `gate_anchor` (최초) | +0.168 | +0.257 | +0.068 |
| `struct_a50` | +0.023 | +0.056 | +0.024 |

- **E50보다 유의하게 좋은 게이트는 없다.** `vol_fb`는 세 평가 모두 차이 없음, `logit2`·`vol_a50`은 2018 MSE에서 조금 나쁘다.
- **초기화의 우연이 사라진다.** 같은 A·C에 게이트 초기화만 20번 바꿨을 때 E50 대비 RMSE 차이의 표준편차가 `gate_vol` 0.066에서 `logit2` 0.002로 줄었다. `gate_vol`은 그 20번 중 65%가 E50보다 나빴다.
- **0.5 anchor는 `gate_anchor`의 불안정을 해소한다.** `struct_a50`은 세 평가 모두에서 `gate_anchor`보다 유의하게 좋다.
- **변동성 신호는 일관되게 학습되지 않는다.** `logit2`는 6회 중 4회에서 검증이 학습을 거부했고, 학습된 2회의 기울기는 +0.67과 −0.05로 부호가 다르다.
- 평가 블록의 A·C 예측을 잡음으로 바꿔도 게이트 학습 결과가 같음을 확인했다.

## 5. 최초 `gate_vol`은 왜 좋아 보였나

- seed 42·44의 무작위 초기값이 우연히 상승형 곡선이었다(전날 표준편차 2 → alpha 0.28, 20 → 0.71, 50 → 0.88). 무작위 초기값 200개 중 상승형은 약 25%다.
- 2018년은 상승형 곡선에 유리했다. 상승형 초기값의 98%가 2018년에 E50을 이긴다.
- 게이트 검증 연도인 2017년은 4개 연도 중 이 패턴이 없는 유일한 해여서 학습이 거부됐다.

**고정 곡선 검증** (`exp_fixed_curve.py`). seed 42의 초기 곡선을 학습 없이 규칙으로 고정하고, 새로 학습한 A·C seed 45–51에 적용했다. 곡선과 판정 기준은 새 seed의 예측을 만들기 전에 코드에 적어 두었다.

| 연도 | RMSE 차이 (곡선 − E50) | 좋은 seed | 판정 |
| --- | --- | --- | --- |
| 2015 | +0.049 | 2 / 7 | 차이 없음 |
| 2016 | −0.151 | 7 / 7 | 유의하게 좋음 |
| 2017 | +0.001 | 4 / 7 | 차이 없음 |
| 2018 | −0.006 | 6 / 7 | 차이 없음 |

사전에 정한 기준으로 **판단 보류**다. 2016년의 이득은 고변동일이 아니라 저변동일에 C 비중을 낮춘 데서 나왔다. 2018년 고변동일의 이득은 새 seed에서 재현되지 않았고, C가 1월에 실패한 seed 45에서는 E50보다 0.46 나빴다. 기울기를 과거 연도에서 학습하는 방식은 seed에 따라 부호가 갈려 실패했다.

## 6. B를 결합에 추가

`exp_add_b.py`. OOF 예측을 만들 때 함께 저장한 B를 썼다(재학습 없음). seed 42–51.

| 모델 (RMSE, seed 10개의 평균) | 2015 | 2016 | 2017 | 2018 |
| --- | --- | --- | --- | --- |
| A | 10.117 | 6.974 | 4.838 | 7.358 |
| B | 10.799 | 7.309 | 5.316 | 7.439 |
| C | 10.592 | 7.697 | 4.917 | 7.043 |
| E50 | 10.224 | 7.022 | 4.690 | 6.980 |
| ABC | 10.270 | 6.869 | 4.635 | 6.692 |
| 과거 연도로 정한 고정 가중치 | – | 7.020 | 4.689 | 6.871 |
| 3개 모델 변동성 게이트 | – | – | 4.656 | 6.738 |

- ABC는 2017·2018년에 seed 10개 전부에서 E50보다 RMSE가 낮다. 그러나 날짜 기준 부트스트랩으로는 유의하지 않고, MAE는 개선되지 않는다.
- B는 단독으로 가장 약하지만 오차가 덜 겹친다(2018 오차 상관 A–C 0.88, A–B 0.71, B–C 0.71).
- 단순 평균이 학습한 가중치와 게이트보다 낫다.

## 7. seed 평균

`exp_seed_average.py`. 같은 날 같은 시각에 대한 seed 10개의 예측을 평균한 뒤 결합했다(재학습 없음).

| 모델 (RMSE: seed 1개 → 10개 평균) | 2015 | 2016 | 2017 | 2018 |
| --- | --- | --- | --- | --- |
| A | 10.117 → 9.994 | 6.974 → 6.591 | 4.838 → 4.476 | 7.358 → 7.004 |
| C | 10.592 → 10.257 | 7.697 → 7.261 | 4.917 → 4.566 | 7.043 → 6.554 |
| E50 | 10.224 → 10.090 | 7.022 → 6.812 | 4.690 → 4.477 | 6.980 → 6.712 |
| ABC | 10.270 → 10.162 | 6.869 → 6.726 | 4.635 → 4.501 | 6.692 → 6.477 |

- **seed 평균의 효과는 4개 연도 모두 유의하다.** 이 문서에서 유일하게 통계적으로 확인된 개선이다.
- **효과의 대부분은 seed 3~5개에서 나온다.** 2018 E50: 1개 7.00, 3개 6.76, 5개 6.73, 10개 6.71.
- **seed 평균 뒤에는 B의 추가 효과가 줄어든다.** ABC − E50이 2017년 +0.024, 2018년 −0.235이고 모두 유의하지 않다.
- **seed 평균 후 C가 A보다 유의하게 좋은 해는 2018년뿐이다.** 2016년은 A가 유의하게 좋고, 2015·2017년은 차이가 없다.

## 한계

- 2017·2018년은 여러 번 분석한 구간이다. 4~7절의 수정과 비교는 그 결과를 본 뒤에 정했다.
- `o2015`·`o2016`의 fold 모델은 1~2년치로만 학습되어 본 모델과 오차 성질이 다르다.
- OOF 구간(2015–2017)에는 2018년 1월 수준의 한파가 없다.
- 2018년의 차이는 소수의 큰 오차일에 몰려 있어 부트스트랩 구간이 넓다.
- 1~3절은 seed 3개 결과다. seed 간 편차가 모델 간 차이보다 크다.

## 실행하지 않은 실험

- 다른 시장(NP·BE·DE 등)에 같은 설정을 그대로 적용하는 독립 재현.
- LEAR 등 구조가 다른 모델을 같은 분할로 학습해 결합에 추가.
- `adaptive-weighted-LSTM-Attention/`의 규칙 게이트를 같은 A·C 예측에 적용한 직접 비교.

## 폴더 구조

이 실험의 파일은 모두 `volatility-gate/` 안에 있다. `PJM_error_analysis/`는 읽기만 한다(A·C 코드 `train_01_baseline.py`·`train_02_bc.py`, 데이터 `data/PJM.csv`, 저장된 결과 `results/abc/`).

```
volatility-gate/
├── README.md
├── requirements.txt
├── vgate_lib.py                 # 시간순 창 로더, 예측 시점 특징, Gating MLP, 지표
├── make_oof_predictions.py      # A·B·C rolling-origin OOF 예측 (기존 train_01/02 함수 재사용)
├── train_volatility_gate.py     # 게이트 학습, ablation (1~3절)
├── analyze_volatility_gate.py   # diagnostic / evaluate
├── exp_gate_fixes.py            # 4절: E50 되돌리기, 0.5 anchor, 2-매개변수 게이트
├── exp_fixed_curve.py           # 5절: 고정 상승 곡선 검증
├── exp_add_b.py                 # 6절: B 추가
├── exp_seed_average.py          # 7절: seed 평균
├── tests/test_volatility_gate.py  # 자동 테스트 20개
├── docs/                        # 요약 표(CSV)와 그래프(PNG)
│   └── followup/                # 4~7절의 요약 표
└── results/                     # 실행하면 생긴다. 저장소에는 올리지 않는다
```

`results/`는 `adaptive-weighted-LSTM-Attention/`과 같은 기준으로 저장소에서 제외했다.

## 실행

```bash
cd volatility-gate
python -m pip install -r requirements.txt
python -m pytest tests/test_volatility_gate.py -q      # 20개 통과 확인
```

1~3절 (seed 42–44, 약 1시간):

```bash
python analyze_volatility_gate.py diagnostic
python make_oof_predictions.py
python train_volatility_gate.py --out results/vgate/main
python analyze_volatility_gate.py evaluate --run results/vgate/main
```

4~7절 (seed 45–51 추가 학습에 2~3시간, 이후 계산은 몇 분):

```bash
python exp_gate_fixes.py
python make_oof_predictions.py --seeds 45 46 47 48 49 50 51
python exp_fixed_curve.py --seeds 45 46 47 48 49 50 51
python exp_add_b.py
python exp_seed_average.py
```

- 위 수치는 맥 M1 CPU(threads 4)에서 얻었다. 같은 seed라도 기기가 다르면 A·C 결과가 조금 달라지므로, 비교표에 들어가는 실행은 모두 한 기기에서 한다.
- 테스트는 게이트 학습이 테스트 블록과 그 이후 행에 영향받지 않는지를 직접 확인한다.
