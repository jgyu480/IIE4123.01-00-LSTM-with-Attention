## 10. 개선 실험

1. 기존 C에 작은 조건부 게이트를 추가한다. 최근 변동성·가격 변화·예보 변화·후보 불일치를 입력으로 하고 게이트 없는 C, 상수 게이트와 비교한다.
2. 가격 수준과 목표일 조건 변화량을 구분한 검색을 시험한다. 후보 수와 다른 학습 조건을 통제한다.
3. 먼 후보나 가격이 충돌하는 후보를 참고할 때 사례 경로를 억제한다. 단순 규칙과 학습형 게이트를 구분한다.
4. 저가격·음수가격 편향을 보정하되 고가격 성능 악화도 확인한다.
5. 추가 시간순 분할에서 고변동 시기의 이득이 재현되는지 평가한다.

## 11. 해석과 평가의 한계

이번 테스트는 오류 탐색에 사용됐다. 이 구간에 맞춰 개선한 뒤 같은 테스트만으로 일반화 성능을 주장하지 않는다. 모델 선택에는 학습·검증을 사용하고 최종 평가에는 추가 시간순 분할을 마련한다. 게이트 학습에는 시간순 외부 예측을 활용해 기본 모델의 학습내 잔차가 지나치게 작게 평가되는 문제를 피한다. 작은 MAE 차이의 유의성은 확정하지 않았으며 날짜를 짝지은 주 단위 블록 부트스트랩 등이 필요하다.
